# Nova.EXE

Autonomous AI Software Engineer.

A project built to understand how AI agents work under the hood, from LLM interaction and tool calling to agent loops, state management, and autonomous task execution.

The goal is to explore and implement the core concepts behind AI agents through a practical, hands-on project.

## Goals

- Local First
- Privacy First
- Tool Based
- Extensible
- Autonomous

## Current Architecture

```text
NovaAgent
    ↓
AgentLoop
    ↓
LLMProvider
    ↓
ToolCall / TextResponse
    ↓
ToolRegistry
    ↓
Tools
    ↓
ToolResult
    ↓
Conversation
```
